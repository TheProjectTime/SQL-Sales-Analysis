# SQL Sales Data Analysis

## Project Overview

This project analyzes a sample sales dataset using SQL to extract
useful business insights.

## Objective

The main objective is to analyze sales data and identify:

- Top customers
- Average order value
- Total revenue
- Sales by category
- Sales by region
- Monthly sales trends
- Top-performing products

## Dataset

The dataset contains 200 sample sales transactions.

The dataset includes:

- Order ID
- Customer Name
- Order Date
- Category
- Sub-Category
- Product Name
- Quantity
- Unit Price
- Total Price
- Region

## Tools Used

- MySQL
- MySQL Workbench
- SQL
- GitHub

## SQL Analysis

### 1. Total Revenue

Calculates the total revenue generated from all orders.

### 2. Average Order Value

Calculates the average value of an individual order.

### 3. Top Customers

Identifies customers who generated the highest total sales.

### 4. Sales by Category

Analyzes revenue generated by different product categories.

### 5. Sales by Region

Compares sales performance across different regions.

### 6. Monthly Sales

Analyzes sales trends month by month.

### 7. Top Products

Identifies the products generating the highest revenue.
